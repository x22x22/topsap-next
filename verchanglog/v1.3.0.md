# v1.3.0

发布日期：2026-11-05

## 概述

TopSAP Client v1.3.0 是 v1.2.2 之后的功能与修复版本。本版重点补齐 macOS 数据面：网卡自检接收方向、自动获取 DNS 的原地址回退、被宽网段覆盖的更具体路由、代理绕过写入权限，并把 macOS helper 白名单收敛到可复用的纯函数校验。同时新增启动版本检查与更新提示，自检超时从 45 秒全局中止改为每个步骤独立 60 秒。Windows 与 Linux 的网卡、路由、DNS 数据面实现未改动。

## 新增

### 启动版本检查

- 启动后读取发布目录中的纯文本版本号（`fileDownload` 地址直接返回版本，不使用 API）
- 仅当远端版本高于当前版本时，在侧栏版本信息旁显示「可更新」/「Update」徽标
- 点击徽标打开与「尚未导入连接配置」同结构的弹窗，提供「稍后」与「前往」
- 「前往」通过系统默认浏览器打开发布目录的 `folder` 下载页
- 网络不可达、HTTP 非 200、版本内容非法时静默跳过，只写调试日志，不影响连接
- 每次启动检查一次，窗口重新聚焦不重复请求

## 修复

### macOS 网卡自检接收方向

- 旧报文目标为测试网段地址，不属于本机，macOS 内核不会回包，导致「接收方向」固定失败
- 改为注入「测试网段 → 本机 VIP」的 ICMP Echo 请求，由系统生成 Echo Reply，按测试路由写回 utun 后由读循环收到
- Windows / Linux 同步使用新的报文目标，接收方向语义保持一致

### macOS DNS 原地址补全

- `networksetup -getdnsservers` 对自动获取返回空，旧实现只写入 VPN DNS
- 手动 DNS 有值时直接作为原 DNS；为空时读取 `scutil --dns` 默认接口解析器（含 IPv6），仍为空则回退 `networksetup -getinfo` 的 `Router`
- 去重后按「VPN DNS 在前、原 DNS 在后」写入，最多 8 个地址；断开时原为自动获取则写回 `Empty`
- 归一化链路本地 IPv6 的 `%作用域` 后缀

### macOS 路由回读

- `route -n get <dest>` 返回最佳匹配而非精确前缀，旧实现只看接口，导致被 `/24` 覆盖的 `/32`、被 `/24` 覆盖的 `/31` 被误判为已存在而跳过
- 回读同时比对 `destination`、`mask` 与接口，兼容省略尾段、`/前缀` 与十六进制掩码
- 删除失败时按 VIP 网关形式补删一次，避免残留

### macOS 代理绕过

- 旧实现自行执行 `networksetup`，普通用户写入 `-setproxybypassdomains` 被系统拒绝且只记录日志
- 改为经 privileged helper 以 root 执行，仅 helper 不可用且进程为 root 时本地回退
- helper 白名单新增 `-getproxybypassdomains` / `-setproxybypassdomains`，校验服务名、条目长度与非法字符，最多 128 条
- `HELPER_VERSION` 升至 `1.2.3`，已安装 helper 会在下次启动时重装并再次请求授权

### 自检超时（全平台）

- 移除 45 秒全局超时；管理员检测、残留清理、创建网卡、配置地址、注入路由、`ping`、读线程回收与最终清理各自独立限时 60 秒
- 某一步超时只把该步骤标记为失败并继续清理，不再中止整个自检
- 接收方向仍保留 3 秒业务判定
- `shell::run` 增加 `kill_on_drop`，超时取消 future 时结束残留的 `netsh` / `route` 子进程

### 英文映射

- 自检明细：发送方向、接收方向、执行超时、`ping` 超时
- macOS：helper 未运行、地址配置失败、TUN 创建/接管失败、系统解析器 IPv6 作用域
- Windows：虚拟网卡/会话创建失败（含 Win32 提示）、设置网卡地址失败（含尝试轮次）、未找到虚拟网卡、非法掩码
- hosts 读写失败；自检明细未命中专用句式时回退到通用后端错误映射

## 安装

- Windows 安装包：`TopSAP Client_1.3.0_x64-setup.exe`，支持 `/S` 静默安装
- Windows 便携版：保留 `resources/wintun.dll` 相对路径，以管理员身份运行
- macOS：首次启动或 helper 版本升级后按提示重新授权 root helper；未签名与公证，首次打开需处理 Gatekeeper
- Linux：需 `sudo /usr/bin/topsap-client` 启动；普通用户双击会弹窗提示

## 已知限制

- macOS 自检、DNS、路由与代理绕过仍需真机回归；纯解析逻辑已用单元测试覆盖，系统命令部分无法在 Windows 上验证
- macOS 升级后 helper 会因版本变化重装一次，需要重新授权
- 版本检查依赖发布目录可达；发布目录版本不高于当前版本时不提示，也不会自动下载或安装
- Windows 自检在「配置网卡地址」偶发耗时较长；本版已改为每步 60 秒超时并在超时后继续清理，根因仍待复现
- Linux 仍未提供 polkit / root helper，GUI 需要以 `sudo` 运行整个应用
- 其余限制同 v1.2.2：仅支持 `ngvone` / `cipher_type=0` 网关；TUN / 透明代理无法使用系统代理绕过；英文模式下的网关动态 `ErrMsg` 仍可能显示中文原文
