# v1.2.2

发布日期：2026-11-05

## 概述

TopSAP Client v1.2.2 是 v1.2.1 之后的修复版本。本版重点修复 Linux / macOS 网卡自检在第 11 项后卡死、Linux 残留网卡导致 `EBUSY`、Linux 未提权启动缺少明确提示、跨平台「记住密码」实际未生效，以及首次启动没有任何连接配置时缺少引导。本版不涉及登录协议字段与隧道数据面改动。

## 修复

### 网卡自检与残留清理

- Unix TUN fd 统一设为非阻塞；读线程每轮 `poll` 后最多读取 32 个报文，`blocking_send` 改为 `try_send`，自检结束后能正常退出
- 增加 `ReaderStopGuard`：自检被 45 秒超时取消时也会停止读线程，避免 TUN fd 泄漏
- `reader.join()` 不再阻塞异步任务，45 秒后端超时恢复生效
- 自检结束前先清理测试路由与网卡，避免异常路径留下 `10.98.0.0/16`、`10.99.99.0/24` 路由
- Linux 自检开始前检查 `topsap0`：仅当接口带有自检地址 `10.99.99.2` 时才执行 `ip link del`，避免误删正在使用的连接网卡
- 自检与连接互斥：连接流程中或存在待清理资源时拒绝自检；自检运行中拒绝连接
- 已连接时拒绝自检的原有判断与提示保持不变

### Linux 提权与错误提示

- Linux 以普通用户启动时弹窗提示改用 `sudo /usr/bin/topsap-client` 重新启动
- Linux 自检第一步与网卡配置失败文案改为具体的 `sudo` 命令，不再出现「系统授权框 / helper」
- `EPERM` / `EACCES` 与 `EBUSY` 分开映射：
  - 权限不足提示需要 root，并给出 `sudo <当前可执行文件>` 命令
  - `topsap0` 被占用提示退出所有实例，或执行 `sudo ip link del topsap0`
- macOS 仍保留 helper / 授权框提示

### 记住密码

- `keyring` 补齐 `apple-native`、`sync-secret-service` 与 `crypto-rust` 后端
- 修复 Linux / macOS 因 keyring 退化为进程内 mock 导致「保存成功但重启后读不到密码」的问题
- Linux 使用 Secret Service，macOS 使用 Keychain，Windows 继续使用凭据管理器；后端不可用时回退为机器绑定 AES-256-GCM 文件
- CI 的 Linux 构建依赖补充 `libdbus-1-dev` / `pkg-config`
- 记住密码说明统一为「保存到系统安全存储」，不再只写「系统凭据管理器」

### 启动引导

- 首次启动且没有任何导入配置、也没有保存过网关时，提示前往「设置」-「连接管理」导入配置
- 提供「稍后」与「前往设置」两个操作；导入配置或保存网关后不再出现
- Linux 未提权提示优先展示，关闭后再展示导入提示，避免弹窗叠加

### 文档

- 同步 `README.md`、`README.en.md`、`docs/ARCHITECTURE.md`、`docs/CHANGELOG.md`
- 补充 Unix 非阻塞 TUN、Linux 残留清理、Linux 提权模型、跨平台凭据后端与启动提示说明
- 新增 Linux `os error 16` 常见问题与配置目录说明
- 修正英文 README 的 WebKitGTK 包名

## 安装

- Windows 安装包：`TopSAP Client_1.2.2_x64-setup.exe`，支持 `/S` 静默安装
- Windows 便携版：保留 `resources/wintun.dll` 相对路径，以管理员身份运行
- macOS：首次启动按提示安装或重新授权 root helper；未签名与公证，首次打开需处理 Gatekeeper
- Linux：需 `sudo /usr/bin/topsap-client` 启动；普通用户双击会弹窗提示

## 已知限制

- Linux 仍未提供 polkit / root helper，GUI 需要以 `sudo` 运行整个应用；这是后续独立改造项
- Linux / macOS 的自检与连接修复需真机回归，尤其是 `topsap0` 清理、`EBUSY` 与记住密码回填
- 使用 `sudo` 启动时若无法访问用户 Secret Service，记住密码会回退为机器绑定加密文件；配置目录以实际 `$HOME` / `XDG_CONFIG_HOME` 为准
- 首次启动导入提示仅在「没有导入配置且未保存过网关」时出现；已有手动连接记录的用户不会被打扰
- macOS / Linux 安装包由 CI 构建；本机未执行完整打包
- 其余限制同 v1.2.1：仅支持 `ngvone` / `cipher_type=0` 网关；TUN / 透明代理无法使用系统代理绕过；英文模式下的网关动态 `ErrMsg` 仍可能显示中文原文
