# v1.1.1

发布日期：2026-11-04

## 概述

TopSAP Client v1.1.1 是 v1.1.0 的修复版本。本版补齐两处「执行后无反馈」的按钮提示，并集中修复中英文切换在自检、连接阶段、短信验证与通用控件上的遗留文案；不涉及协议、隧道与数据面改动。

## 修复

### 代理绕过「恢复默认」

- 保留用户自定义条目，只补齐缺失的 `*.sunline.cn` 与 `*.sunline-i.com`
- 补齐成功后提示「已恢复默认代理绕过条目」
- 默认条目已齐全时提示无需恢复，不再静默执行
- 保存后仍按原有逻辑写入系统代理绕过列表，只管理本应用写入的条目

### 残留检查「重新检查」

- 重新读取 hosts 标记段，检查完成后提示「未发现 hosts 残留」或「检测到 hosts 残留，可点击清理」
- 读取失败时提示「检查失败」并显示原因，不再出现点击无反馈
- 明确该检查只覆盖 hosts 标记段，不检查路由残留

### 中英文切换

- 网卡自检：步骤名称与结果明细支持英文，新增 `selfTestText` 句式映射，覆盖建卡、地址、路由、收发、ping 与 wintun 错误
- 连接阶段：补齐「正在检查上次会话」「正在配置网卡地址」等明细
- 短信 / 企业微信验证码：失效原因与动态口令提示支持英文
- 通用界面：下拉框默认占位、错误重试按钮、代理绕过输入框示例文案
- 设置窗口：修正空连接状态文案的翻译 key 不一致
- 常见会话与连接错误补充英文映射：操作进行中、线路不可用、路由注入失败、会话失效等

## 平台支持

| 平台 | 状态 |
| --- | --- |
| Windows 11 / 10 x64 | 已验证 |
| Windows 11 / 10 ARM64 | 已实现，待真机验证 |
| Windows 7 SP1 | 兼容路径，需 WebView2 109 与 VC++ 运行库 |
| macOS Intel / Apple 芯片 | 特权 helper 已实现，待真机验证 |
| Linux amd64 / arm64 | 已实现，待真机验证；代理绕过仅支持 GNOME |

## 验证

- `npx tsc --noEmit` 通过
- `npm test` 通过：4 个测试文件、30 项用例
- 新增 `selfTestText` 测试 3 项，`errorText` 新增会话错误测试 1 项
- 本版未改动 Rust 代码，沿用 v1.1.0 的 Rust 编译与单元测试结果
- 未在桌面上手工回归 toast 与语言切换的视觉效果

## 安装

- Windows 安装包：`TopSAP Client_1.1.1_x64-setup.exe`，支持 `/S` 静默安装
- Windows 便携版：保留 `resources/wintun.dll` 相对路径，以管理员身份运行
- macOS：首次启动按提示授权安装 root helper；未签名与公证，首次打开需处理 Gatekeeper
- Linux：需 `sudo` 启动，安装 WebKitGTK 4.1 运行时

## 已知限制

- macOS 特权 helper 只代理 TUN 创建与 `ifconfig`/`route` 白名单命令，不包含 `/etc/hosts` 写入；helper 模式下清理 hosts 残留可能因权限失败，需要以 root 运行或手动处理
- hosts 检测读取失败时按「无残留」展示，无法区分文件不存在与读取失败
- 英文模式已覆盖界面文案与常见错误，但后端低层系统错误（wintun、系统命令、配置读写等）仍可能显示中文原文
- 连接日志面板展示后端原始中文日志，不随界面语言切换
- 其余协议与平台限制同 v1.1.0：仅支持 `ngvone` / `cipher_type=0` 网关；TUN/透明代理无法使用系统代理绕过；macOS / Linux 数据面尚未完成真机连接回归
