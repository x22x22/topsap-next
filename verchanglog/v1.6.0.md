# v1.6.0

发布日期：2026-11-13

## 概述

TopSAP Client v1.6.0 为托盘图标增加连接状态提示：保留应用原图标的完整外观，只把盾牌主色按状态替换。未连接为灰色、已连接为绿色、连接过之后断开为橙色并闪烁。此前托盘图标始终是同一张彩色应用图标，窗口隐藏后无法从菜单栏判断 VPN 当前状态。

## 新增

### 托盘连接状态图标

- 图标直接使用应用原图标的完整像素内容：深色圆角底座、盾牌轮廓、齿轮细节全部保留，尺寸与原图标一致，不会变小或丢细节；仅把「青色盾牌」区域的像素替换成状态色。
- 三种状态：
  | 状态 | 颜色 | 表现 |
  | --- | --- | --- |
  | 未连接 | 灰色 `#8E8E93` | 启动后从未连接成功 |
  | 已连接 | 绿色 `#34C759` | 当前隧道已建立，静态 |
  | 已断开 | 橙色 `#FF9500` | 连接过之后主动断开、掉线或失败；约 0.7 秒在亮/暗橙色间闪烁 |
- 状态由 `Engine::set_phase` 驱动：`Connected` 置为已连接并记录「曾经连接成功」，其余阶段按是否连接过显示灰色或橙色，因此断开后不会退回「未连接」。
- 闪烁由独立异步任务驱动，仅在「已断开」状态交替亮/暗（暗态为状态色按 0.55 压暗），其他状态保持静态并重置闪烁相位。
- 托盘 tooltip 同步显示「TopSAP Client · 未连接 / 已连接 / 已断开」。
- 状态用进程内原子量去重，阶段在连接流程中反复切换时只在状态真正变化时调用系统接口。
- macOS 显式关闭模板渲染（`icon_as_template(false)`，运行期替换后再设一次），避免状态色被系统按黑白模板抹平。

## 平台支持

| 平台 | 状态 |
| --- | --- |
| macOS Intel / Apple 芯片 | 托盘状态图标生效；已关闭模板渲染保留颜色 |
| Windows 11 / 10 / Windows 7 | 托盘状态图标生效 |
| Linux amd64 / arm64 | 托盘状态图标生效（取决于桌面环境是否显示托盘图标） |

## 已知限制

- 图标尺寸沿用原应用图标像素，由系统缩放到菜单栏大小，未额外提供多倍图。
- 闪烁仅在「已断开」状态出现；连接中（登录/建链）按状态显示为灰色或橙色，不闪烁。
- 菜单栏图标在极端主题（如高对比度模式）下对比度可能降低，未做主题自适应。
