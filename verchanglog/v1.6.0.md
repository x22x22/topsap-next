# v1.6.0

发布日期：2026-11-13

## 概述

TopSAP Client v1.6.0 为托盘图标增加连接状态区分：在应用原图标（盾牌）基础上按状态着色，未连接为灰色、已连接为绿色、连接过之后断开为橙色。此前托盘图标始终是同一张彩色应用图标，窗口隐藏后无法从菜单栏判断 VPN 当前状态。

## 新增

### 托盘连接状态图标

- 托盘图标由应用原图标派生，**保留原图标的盾牌轮廓与齿轮镂空**：先做盒式降采样到 36×36，再按亮度把深色圆角底与齿轮压成透明（保留抗锯齿），最后用状态色填充。
- 三种状态：
  | 状态 | 颜色 | 说明 |
  | --- | --- | --- |
  | 未连接 | 灰色 `#8E8E93` | 启动后从未连接成功 |
  | 已连接 | 绿色 `#34C759` | 当前隧道已建立 |
  | 已断开 | 橙色 `#FF9500` | 连接过之后主动断开、掉线或失败 |
- 状态由 `Engine::set_phase` 驱动：`Connected` 置为已连接并记录「曾经连接成功」，其余阶段按是否连接过显示灰色或橙色，因此断开后不会退回「未连接」。
- 托盘 tooltip 同步显示「TopSAP Client · 未连接 / 已连接 / 已断开」。
- 状态用进程内原子量去重，阶段在连接流程中反复切换时只在状态真正变化时调用系统接口。
- macOS 显式关闭模板渲染（`icon_as_template(false)`，运行期替换后再设一次），避免状态色被系统按黑白模板抹平。

## 平台支持

| 平台 | 状态 |
| --- | --- |
| macOS Intel / Apple 芯片 | 托盘状态图标生效；已关闭模板渲染保留颜色 |
| Windows 11 / 10 / Windows 7 | 托盘状态图标生效 |
| Linux amd64 / arm64 | 托盘状态图标生效（取决于桌面环境是否显示托盘图标） |

## 验证

- `cargo fmt --check` 通过
- `cargo clippy --all-targets -- -D warnings -A deprecated` 通过，零告警
- `cargo test --lib` 通过：192 项（新增状态推导、三态颜色/文案、着色剪影 3 项）
- 已用同一算法在 36×36 预览网格上核对：深色与浅色背景下均保留盾牌形状，齿轮镂空，灰/绿/橙可清晰区分

## 已知限制

- 图标固定 36×36（约 18pt @2x），未针对不同桌面缩放提供多倍图。
- 着色为单色剪影，原图标的青色渐变不会保留（这是保留形状并区分状态色的取舍）。
- 菜单栏图标在极端主题（如高对比度模式）下对比度可能降低，未做主题自适应。
