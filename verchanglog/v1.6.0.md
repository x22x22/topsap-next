# v1.6.0

发布日期：2026-11-13

## 概述

TopSAP Client v1.6.0 为托盘图标增加连接状态区分：未连接时显示灰色空心圆环，已连接后变为绿色实心圆点。此前托盘图标始终是同一张应用图标，窗口隐藏后无法从菜单栏判断 VPN 是否已连上。

## 新增

### 托盘连接状态图标

- 新增 `tray_status` 模块：按「是否已连接」加载不同图标（`icons/tray-off.png` 灰色空心圆环、`icons/tray-on.png` 绿色实心圆点，36×36 抗锯齿 PNG）。
- 托盘创建时使用未连接图标，并显式关闭 macOS 模板渲染（`icon_as_template(false)`），避免颜色被系统按黑白模板处理；运行期替换图标后再次关闭模板渲染。
- 由 `Engine::set_phase` 驱动：只有 `Connected` 阶段显示已连接样式，进入重连、断开或失败阶段时自动回退为未连接样式。
- 状态用进程内原子量去重，阶段在连接流程中反复切换时只在「是否已连接」真正变化时调用系统接口。
- 托盘 tooltip 同步显示「TopSAP Client · 已连接 / 未连接」。

## 平台支持

| 平台 | 状态 |
| --- | --- |
| macOS Intel / Apple 芯片 | 托盘状态图标生效；已关闭模板渲染保留颜色 |
| Windows 11 / 10 / Windows 7 | 托盘状态图标生效 |
| Linux amd64 / arm64 | 托盘状态图标生效（取决于桌面环境是否显示托盘图标） |

## 已知限制

- 菜单栏图标尺寸固定为 36×36（约 18pt @2x），未针对不同桌面缩放做多倍图。
- 颜色在浅色与深色菜单栏下均可辨认，但未做系统主题自适应（保持固定灰/绿）。
