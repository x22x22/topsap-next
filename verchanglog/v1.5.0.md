# v1.5.0

发布日期：2026-11-13

## 概述

TopSAP Client v1.5.0 补齐两处现场高频诉求：macOS 上关闭窗口后 Dock 图标的行为，以及登录后网关下发路由的生效范围控制。

macOS 下此前的「关闭窗口最小化到托盘」只隐藏窗口，Dock 图标始终保留；同时因为缺少 `applicationShouldHandleReopen` 处理，点击 Dock 图标无法把隐藏的窗口唤回。本版本修复后者，并新增「关闭窗口后隐藏 Dock 图标」开关，可只保留菜单栏托盘。

路由方面，设置窗口新增「路由生效范围」：列出登录后网关下发的全部网段，可逐条勾选、全部启用或全部关闭，也可手动排除网关未下发但需要避开的网段。被关闭的网段不写入系统路由表，也不参与连接前的路由冲突检测与自动重连恢复，适合与本地网络同网段、或只想让部分内网走隧道的场景。

## 新增

### macOS 窗口与 Dock 行为

- 新增设置项「关闭窗口后隐藏 Dock 图标」（`hide_dock_when_closed`，仅 macOS 展示，默认关闭，仅在「关闭窗口时最小化到托盘」开启时可用）：关闭窗口时调用 `set_dock_visibility(false)` 隐藏 Dock 图标，只保留菜单栏托盘图标。
- 恢复窗口统一走 `reveal_main_window`：显示并聚焦主窗口，同时恢复 Dock 图标。托盘菜单「显示主窗口」、托盘左键点击、二次启动与 Dock 图标点击都复用该路径。
- 处理 `RunEvent::Reopen`（macOS `applicationShouldHandleReopen`）：修复关闭到托盘后点击 Dock 图标无反应、窗口唤不出的问题。
- Dock 状态用进程内原子量去抖，仅在状态真正变化时调用系统接口，规避 `TransformProcessType` 在 1 秒内反复切换导致 macOS 残留多个 Dock 图标的已知问题。

### 隧道路由生效范围

- 新增设置区块「路由生效范围」：按网段列出本次（或上次）登录由网关下发的全部隧道路由，显示 CIDR、掩码与生效状态，支持搜索、逐条开关、全部启用与全部关闭。
- 被关闭的网段在 `session.routes` 上过滤：不写入系统路由表、不参与连接前的路由冲突预检与接管、重连后也不恢复，日志记录「已按设置排除 N 条隧道路由」。
- 设置项 `disabled_routes` 以 `目的地址/前缀` 持久化；保存时归一化为网络地址、去重、跳过非法项，上限 256 条。
- 每次登录把网关下发的完整路由写入配置目录 `routes_cache.json`，未连接时设置页仍可勾选；手动排除列表可单独添加/撤销网关未下发的网段，支持 `10.0.0.0/8` 与 `10.0.0.0 255.0.0.0` 两种写法。
- 新增命令 `route_policy`，返回路由列表、来源（当前会话 / 上次登录缓存）与在线状态。

## 变更

- 关闭窗口语义补齐：未开启「关闭窗口时最小化到托盘」时，关闭窗口即退出程序（先走既有退出清理再结束进程），不再留下没有窗口、Dock/托盘图标却点不开的驻留进程。
- 保存设置时只有代理绕过配置发生变化才重写系统代理，避免在设置页反复勾选路由时反复调用 `networksetup` 等系统接口。
- 路由勾选与 Dock 开关均随设置即时落盘，修改对下一次连接生效（连接中不热替换已注入的路由）。

## 已知限制

- 路由生效范围只影响客户端是否把网段写入系统路由表，不改变网关侧的 ACL 策略；关闭后访问这些网段会走本地网络。
- 连接进行中修改勾选不会热更新已注入的路由，需要断开重连后才按新设置生效。
- macOS 的 Dock 隐藏基于进程级 `TransformProcessType`；1 秒内极快地「关闭 → 重新打开」时，系统可能短暂保留图标，属 macOS 已知行为。
