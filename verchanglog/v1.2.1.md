# v1.2.1

发布日期：2026-11-04

## 概述

TopSAP Client v1.2.1 是 v1.2.0 之后的修复版本。本版优化网卡自检的跨页状态、逐项展示与残留清理，修复 macOS 连接后路由未写入与 DNS 设置失败，并补齐找回密码成功提示。本版不涉及登录协议字段与隧道数据面改动。

## 修复

### 找回密码

- 重置成功提示补充「（新密码已自动填入）」，带接收方的提示同样补充
- 与登录表单自动回填新密码的行为保持一致
- 中英文词条同步

### 网卡自检

- 切换到其他页面后保持自检运行，按钮继续旋转并禁用，返回诊断页时结果仍在
- 每一步完成后立即展示，不再等全部结束；新增「自检进行中」「自检中断」「已完成 N 项」状态
- 自检开始前新增「清理上次自检残留」：
  - Windows 10/11 使用 `Get-NetAdapter` + `Remove-NetAdapter`
  - Windows 7 使用 `netsh interface set interface` 禁用再启用
  - macOS / Linux 使用系统 TUN，无需清理
- `Win32 1247` 映射为「网卡会话已存在或网卡状态异常，请清理残留网卡后重试」
- 自检结束后再次清理适配器，避免残留网卡
- 新增 45 秒总超时与并发运行保护；已连接时拒绝自检，避免误删正在使用的网卡

### macOS 路由与 DNS

- 依据官方客户端 3.6.2.46.3 的 `libTopSecVPN` 字符串还原网络行为
- 路由添加改为 `route -n add -net <目标网段> -netmask <点分掩码> <VIP>`，不再使用 macOS 不识别的 CIDR + `-interface` 形式
- 路由校验改为 `route -n get <dest>` 并匹配 `interface:`；删除使用 `-netmask <mask> -interface <ifname>`
- DNS 通过 `networksetup` 写入当前网络服务：VPN DNS 在前、原 DNS 在后；断开时恢复原列表，原为自动获取则写回 `Empty`
- helper 增加 `networksetup` 严格白名单（只允许读取服务与设置 DNS）
- helper 版本独立为 `1.2.1`，启动探活不一致会触发已安装 helper 重装
- Windows `set_dns` 同步支持 dns1/dns2
- 引擎 DNS 日志显示两个 DNS；Linux 明确提示「Linux 不修改系统 DNS」，不再误报失败

## 安装

- Windows 安装包：`TopSAP Client_1.2.1_x64-setup.exe`，支持 `/S` 静默安装
- Windows 便携版：保留 `resources/wintun.dll` 相对路径，以管理员身份运行
- macOS：首次启动按提示重新授权安装 root helper（版本 `1.2.1`）；未签名与公证，首次打开需处理 Gatekeeper
- Linux：需 `sudo` 启动，安装 WebKitGTK 4.1 运行时

## 已知限制

- macOS 路由/DNS 修复依据官方 pkg 静态逆向，仍需 Intel 与 Apple 芯片真机回归
- macOS 的 DNS 服务识别以默认路由设备为准，多活动网络服务场景需真机确认
- Windows 7 的自检残留清理使用 `netsh` 重置网卡状态，需真机回归
- 本版未在本地重新打包；Release 安装包由 CI 构建后附加
- 其余限制同 v1.2.0：仅支持 `ngvone` / `cipher_type=0` 网关；TUN/透明代理无法使用系统代理绕过；英文模式下的网关动态 `ErrMsg` 仍可能显示中文原文
