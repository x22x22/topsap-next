# v1.5.2

发布日期：2026-11-13

## 概述

TopSAP Client v1.5.2 是 v1.5.1 的补充修复版本，补齐启动自动连接成功后的连接提示与空资源保护，使自动连接与手动连接的行为保持一致。

## 修复

### 自动连接缺少成功提示与空资源保护

- 根因：连接成功 toast 与「资源 / 路由为 0 时提示并自动断开」的逻辑此前只写在 `useConnect` 的 `onSuccess` 中，仅手动连接会触发；启动自动连接由后端 `autostart` 直接调用 `Engine::connect`，前端不会执行该回调。
- 将「空资源保护 + 成功提示」抽为 `notifyConnected()`：手动连接与自动连接共用同一入口，自动连接补拉会话摘要后同样弹出「已连接，虚拟 IP …」提示（含网关与路由条数）。
- 自动连接后若网关未下发门户资源或可注入路由，现在与手动连接一致：提示「用户未拥有任何资源地址，请联系管理员」并自动断开，不再停留在无资源的已连接状态。
- 新增 `isSessionEmpty()` 纯函数统一空资源判定，配套 3 项单元测试。

## 平台支持

| 平台 | 状态 |
