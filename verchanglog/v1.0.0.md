# v1.0.0

发布日期：2026-11-03

## 概述

TopSAP Client v1.0.0 是项目首个正式版本。客户端以 Tauri 2 + Rust + React 19 重写 TopSAP / 天融信 NGVONE SSL VPN 的完整链路，覆盖登录、二次认证、隧道、虚拟网卡、路由与 DNS 配置、连接信息展示与系统集成。

## 核心功能

- 账号密码登录、图形验证码、动态验证码二次认证（短信 / 企业微信）
- 登录三步骤、图形验证码 Cookie 复用、`-40135` 自动刷新与重试
- 16 字节协议帧、TLS 长连接、双向数据泵、异常断开自动重连
- Windows Wintun / macOS、Linux 系统 TUN 数据面
- 按 ACL 目标与资源 `ip/mask` 下发路由，断开按账本清理
- 连接配置管理：多配置、多线路优选/备份、导入导出、默认配置
- 忘记密码两步流程、密码到期/首登/管理员要求改密
- 连接后资源列表、基本信息、流量曲线、登录历史
- 设置窗口：通用、连接管理、代理绕过、外观、关于
- 系统代理绕过：Windows `ProxyOverride`、macOS `networksetup`、Linux GNOME `gsettings`
- 深色/浅色主题、中英文切换、侧栏折叠、顶部 toast
- 系统托盘、单实例、关闭到托盘、退出前断开
- 凭据优先系统钥匙串，回退机器绑定 AES-256-GCM 加密文件

## 本轮重点修复

- 忘记密码：`-40075` /「禁止找回密码」显示「该用户不存在或已被禁用」；`-40052/-40071` /「找回密码失败」显示「新密码不能与旧密码一致」；第二步 `-40230` 按成功处理并自动关闭弹窗
- 图形验证码：选路探测的 `auth_param` Cookie 继续用于 `gid` 与 `user_pswd`，修复 `cgid`/`topsecsvkkk` 丢失导致的 `-40135`；验证码错误自动刷新，最多 3 轮
- 动态验证码：按官方客户端日志改为 `POST /vone/login/user_pswd`，表单 `U/SMS/SMS_TIME=0/HASH/S_CODE`，复用密码请求的 `HASH/S_CODE` 与挑战 Cookie
- 密码输入框：隐藏 WebView 原生眼睛，右侧固定显示/隐藏按钮，覆盖登录、忘记密码、到期改密与已连接改密
- 改密提示：成功类 toast 使用 Sonner `richColors` 原生样式；新旧密码相同前端预检并映射 `-40037/-40129`
- 改密重登：新密码自动填入登录框，重新登录成功 toast 提示「登录密码已自动填入」
- 无资源连接：`-40123` 与连接后无资源统一提示「用户未拥有任何资源地址，请联系管理员」并自动断开
- 路由下发：按 ACL 目标与资源 `ip/mask` 并集注入，修正网关把 IPv4 目标写在 `d_ip_v6` 导致路由缺失的问题，隐藏资源仍参与路由
- 测试数据：清理真实内网地址与域名，统一使用 RFC 5737 文档地址与 `example.com`

## 安装

- Windows 安装包：`TopSAP Client_1.0.0_x64-setup.exe`，支持 `/S` 静默安装
- Windows 便携版：保留 `resources/wintun.dll` 相对路径，以管理员身份运行
- macOS：需 `sudo open` 启动；未签名与公证，首次打开需移除 Gatekeeper 隔离
- Linux：需 `sudo` 启动，安装 WebKitGTK 4.1 运行时

## 已知限制

- 仅支持 `ngvone` / `cipher_type=0` 网关；国密网关暂未实现
- 代理绕过的规则/全局模式仅对使用系统代理的程序生效，TUN/透明代理模式无法覆盖
- Linux 代理绕过仅支持 GNOME `gsettings`，KDE 等桌面暂未实现
- macOS / Linux 数据面尚未完成真机连接回归
- macOS 应用未做 Apple 签名与公证
